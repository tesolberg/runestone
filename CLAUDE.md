# Norse TTRPG — Project Instructions

## Language & voice
- All rulebook and scenario content is written in English.
- Tone: sword-and-sorcery, grounded Norse aesthetic — avoid high-fantasy or generic D&D phrasing.
- Rules text should be precise and unambiguous, written for print (clear headers, consistent terminology).

## System reference (keep consistent across all files)
- Dice mechanic: custom xd6 pool — always verify probability claims mathematically, don't eyeball them

## Working style
- When adding or changing a rule, check it against existing rules for consistency before writing.
- Flag any rule that would require rebalancing combat math rather than silently applying it.
- Prefer editing existing files over creating new ones unless starting a clearly new rule section or scenario.

## Do not
- Mix English rules terminology into the Norwegian text without a reason
